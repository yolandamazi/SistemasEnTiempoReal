<h1 align="center"> ⏱️ Real-Time Systems Labs</h1>

![Ada](https://img.shields.io/badge/Ada-800080?style=for-the-badge&logo=ada&logoColor=white)

A series of labs for Real-Time Systems, implemented in Ada, covering key concepts in real-time programming. Each lab focuses on a specific aspect of real-time systems, including task timing, inter-task communication, interrupt handling, synchronization, shared resource management, inter-process communication, and error handling.

---

### 📁 Project Structure
- `P0/`: Lab 0 – Initial setup of the development environment.
- `P1/`: Lab 1 – Implementation of a real-time timing system.
- `P2/`: Lab 2 – Development of an inter-task communication system.
- `P3/`: Lab 3 – Implementation of an interrupt management system.
- `P4/`: Lab 4 – Development of a task synchronization system.
- `P5/`: Lab 5 – Implementation of a shared resource management system.
- `P6/`: Lab 6 – Development of an inter-process communication system.
- `P7/`: Lab 7 – Implementation of an error management system
